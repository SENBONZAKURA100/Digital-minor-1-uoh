Q2 — Blocking vs Non-Blocking

This experiment demonstrates the difference between blocking and non-blocking assignments. Non-blocking assignments are used to correctly swap values in sequential logic.

This experiment implements a counter-based seat-belt warning system. The buzzer activates after the required number of clock cycles when the seat belt remains unbuckled.
